# Bety Gebremeskel — Portfolio

Personal site for Bety Gebremeskel, a full-stack software engineer.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

- Add GitHub / LinkedIn URLs in `src/app/page.tsx` and `src/components/Nav.tsx`
- Replace project copy if you have live demos or repos
- Deploy on [Vercel](https://vercel.com)
